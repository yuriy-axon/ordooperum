# Product Vision

## Summary

Ordo Operum is a task-organization system delivered as a **web application** and **mobile applications**. It is built in phases, starting with AI agents that help the owner organize their tasks, then growing into a full application on top of what those agents establish.

## Platforms

- Web application
- Mobile applications (iOS, Android)

## Phases

| Phase | Goal | Status |
|-------|------|--------|
| 1 | **Agents** — Claude Code skills that capture, structure, prioritize and help execute tasks | In progress |
| 2 | **Application** — web and mobile apps built around the task model and agents from Phase 1 | Not started |

## Primary user

The project owner, managing their own tasks. Multi-user or team use is out of scope until decided otherwise.

## Open questions

- What sources do tasks come from today (notes, email, calendar, Jira, chat)?
- Which tool, if any, is the current source of truth for tasks?
- What does "organized" mean in practice: prioritized list, daily plan, projects, deadlines, contexts?
- Mobile approach: native, React Native/Expo, Flutter, or PWA first?
